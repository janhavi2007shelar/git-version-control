# Git Version Control Project

## Aim
To perform basic version control operations using Git and GitHub.

## Introduction
Git is a distributed version control system used to track changes in files and coordinate work on software projects. GitHub is a platform for hosting Git repositories online.

## Tools Required
- Git
- GitHub
- Visual Studio Code
- Windows operating system

## Operations Performed
1. Initialized a Git repository using `git init`.
2. Checked repository status using `git status`.
3. Added files to the staging area using `git add`.
4. Saved changes using `git commit`.
5. Viewed commit history using `git log`.
6. Created and switched branches using `git branch` and `git switch`.
7. Merged branches using `git merge`.
8. Uploaded the project to GitHub using `git push`.

## Project File
- `index.html` — a sample HTML file used to practise Git version control.

## Result
Successfully performed basic Git version control operations and uploaded the project to GitHub.
